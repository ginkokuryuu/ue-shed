# UE Shed 0.13.0

UE Shed 0.13.0 makes Game Text say plainly when localization files are missing from a working copy,
and moves Map History to `p4client-ts` 0.12.1 with typed Perforce failures. All 20 public npm
packages and eleven Unreal plugins advance to 0.13.0 together; packages without direct changes
advance for suite alignment and exact dependencies.

## Game Text: missing localization files

- A manifest, archive or PO file the working copy does not have now reads
  "Not in this working copy: <path>" with a Gather or Export recovery. Files that exist but fail to
  read or parse keep "could not be read" with their error code. The generic missing-evidence labels
  no longer claim a read failure.
- Ready `LocalizationTargetResult` values gain optional `fileProblems` and `localizationFolder`.
  `WorkspaceReportPage` gains optional `gatherFilesMissing`, `gatherFileProblems` and
  `localizationFolder`. Problems are bounded `LocalizationFileProblem` values without file
  provenance.
- New exports: `LocalizationFileProblem`, `localizationFileProblems`, `explainLocalizationFile`,
  `localizationEvidenceFolder` and `localizationTargetFiles`. `localizationManifestFailure`
  accepts the manifest's relative path, and the CLI localization workflows pass it.
- Workbench's Game Text localization view and reports show the missing files and the folder Game
  Text looked in.

## Map History: p4client-ts 0.12.1

- `@ue-shed/map-history` requires `p4client-ts@0.12.1` (previously 0.7.1).
- Perforce failures that previously returned empty results surface as typed Map History errors:
  permission failures map to `perforce_authentication`, paths outside the client view to
  `ambiguous_depot_mapping`, and unknown user or charset failures to `perforce_configuration`.
  A missing revision during materialization surfaces as `perforce_command`.

## Release tooling

- Packing public packages builds them in workspace dependency order, so a pack from a checkout with
  no prior build output succeeds. `pnpm release:pack:clean-check` proves this from a temporary
  worktree of the committed release.

## Upgrade notes

Use matching 0.13.0 packages and plugin artifacts. Map History consumers must install the exact
`p4client-ts@0.12.1` alongside the package:

```powershell
npm install --save-exact @ue-shed/map-history @ue-shed/protocol @ue-shed/unreal-assets effect@4.0.0-beta.98 p4client-ts@0.12.1
```

Callers that treated an empty Map History result as "no history" should handle the new typed
Perforce errors. Game Text additions are optional fields and new exports; existing readers are
unaffected.

Unreal plugins have no behavioral changes in this release; they advance for suite alignment.
Native plugin compatibility targets Unreal 5.7 and 5.8. Compiled variants require matching engine
version, BuildId, platform and architecture.
