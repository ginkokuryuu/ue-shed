# UE Shed 0.16.2

UE Shed 0.16.2 keeps a host's event loop running while Game Text builds its index. On large projects
a cold build blocked a server host for up to 13 s, long enough for a host's progress requests to time
out. All public npm packages and Unreal plugins advance to 0.16.2 together; packages without direct
changes advance for suite alignment and exact dependencies.

## Game Text: index builds yield to the host

- **Why it blocked.** Effect yields to the event loop after 2,048 operations in one fiber run, and
  every promise resume starts a new run. The index build alternates synchronous work with promises
  that settle from memory, so it never reached a macrotask. Separately, several passes ran 1–3 s in
  one synchronous call.
- **Scheduler.** `GameTextIndexSteps` methods run on `HostSliceScheduler`, which yields once the event
  loop has gone 16 ms without a turn, whatever the operation count.
- **Sliced passes.** Duplicate places and sources, query columns, query places, locale and row sorts,
  package selection, the cold string sort and the inventory sort yield between bounded slices. Sorts
  use a stable sliced merge that gives the native sort's order. Synchronous exports are unchanged.
- **Same output.** On a large project, every raw text row, 46 query responses and 11,549 decoded
  snapshot sections match 0.16.1. No cache key changes, so updating does not rebuild the index.
- **Measured** with 100 ms health polling on two large projects (cold build, 0.16.1 → 0.16.2): the
  longest wait for a health request went from 13,094 ms to 548 ms and from 7,752 ms to 1,141 ms.
- **Still blocking:** opening the finished query model (`openTarget`) builds it synchronously and can
  block for up to about a second, as in 0.16.1.

## Validation

Release preparation on 2026-10-16 uses Node 26 (selected by pnpm) and pnpm 11.17.0.

- The hosted repository gate passed on #96 and runs the portable gate (`pnpm check`) over the release
  commit on the release pull request.
- An independent review of #96 ran `pnpm run check:precommit` and the Game Text suite (531 passed),
  plus the downstream Electroswag checks and Game Text service tests against the packed build.
- Clean pack (`pnpm release:pack:clean-check`): all public packages packed from a clean checkout of
  the release commit.
- The engine matrix (`pnpm test:uasset-engine-matrix`) and `pnpm check:unreal` were not run. This
  release has no reader, native or plugin changes; the Rust crates and Unreal plugins change only
  their version since 0.16.1.
