# UE Shed 0.16.1

UE Shed 0.16.1 makes Game Text's key and duplicate signals stricter and its quality workspace responsive on large projects. Duplicate-source review no longer pairs text with its own re-keyed or unresolved identity. Conflicting keys are measured by their longest text. Terminology matches only whole words. The quality workspace no longer builds every source finding up front, and its findings name the place they affect. All public npm packages and Unreal plugins advance to 0.16.1 together; packages without direct changes advance for suite alignment and exact dependencies.

## Game Text: fewer false positives

- **Same text, other key** (`duplicate_source`) now needs a counterpart with a different identity and a different place.
    - A re-keyed field's old gathered key and new saved key describe one place, so they no longer pair.
    - Places are compared by package, object and field, including the DataTable row and String Table entry. Case, slashes and array spelling are normalised; String Table entry keys stay case-sensitive.
- **Unresolved text.** Text without a resolved key is left out of both sides of duplicate-source signals.
- **Conflicting keys.** A key whose saved texts differ is measured by its longest text, not all of them joined: for `long`, character counts and word counts.
- **Terminology.** Literal terms match only at word boundaries: not beside a Unicode letter, mark or number. Combining marks and Indic vowel signs count as part of the word. Case handling, phrases, punctuation and UTF-16 offsets are unchanged.

## Game Text: index and workspace performance

- **Joined index.** It stores per-occurrence place IDs and sources, so duplicate-source updates after an edit stay incremental. On a generated 238,000-line corpus, a one-edit refresh took 0.29 s, against 0.43 s in 0.16.0. The full build is within 1% of 0.16.0.
- **Cache key.** The joined cache key moves to `joined-v18`, so the first scan after updating rebuilds the joined index.
- **Quality workspace** (`localizationQualityWorkspaceOf`):
    - builds source items only for the page shown;
    - can take an optional compact `groups` index and `sourceKeyOfUnit` metadata;
    - caches the current selection and pages by rank.
- **Measured** on a generated 238,000-line, ten-culture corpus: the longest event-loop gap went from 160 s to 24 ms, and the first page from 329 ms to 18 ms.
- **For hosts:** `LocalizationFindingList.groups` and `LocalizationQualityMetadata.sourceKeyOfUnit` are optional. Providers that supply them must keep them consistent with their immutable scan facts.

## Game Text: finding places

- **Quality workspace findings name their place.** `WorkspaceFinding` gains optional `location` (the first place the finding affects) and `locations` (how many places it affects). Hosts can name the place the way they name a line's places, instead of showing a hashed key from `context`, which is unchanged.

## Validation

Release preparation on 2026-10-15 uses Node 26.12.0 and pnpm 11.17.0.

- The hosted repository gate passed on each merged change (#91, #92, #94). On the release pull request it runs the portable gate (`pnpm check`) over the release commit.
- Clean pack (`pnpm release:pack:clean-check`): all 20 public packages packed from a clean checkout of the release commit.
- The engine matrix (`pnpm test:uasset-engine-matrix`) was not run. This release has no reader or native changes; the Rust crates and Unreal plugins change only their version since 0.16.0.
