# UE Shed 0.15.0

UE Shed 0.15.0 reports Game Text's source-level localization findings once per line instead of once
per culture, keeps full object paths on text read from UE 4.27 packages, and fixes opening a full
Game Text join whose source strings were already published. All 20 public npm packages and eleven
Unreal plugins advance to 0.15.0 together; packages without direct changes advance for suite
alignment and exact dependencies.

## Game Text: source-level findings once per line

- `missing_translator_notes` and `duplicate_source` describe the source line, so each now reports
  once per line instead of once for every culture in the target. On a generated 10-culture target
  the quality scan's findings fell from 2,027,740 to 227,047; the other checks are unchanged.
- The finding belongs to the target's native culture, or to the line's first culture in the target
  by code when it has no native one. The all-cultures list counts each line once; selecting the
  native culture shows these findings, and selecting another culture does not.
- Counts, rule summaries, search, export, focus and fix counts follow, on both
  `checkLocalizationTarget` and the indexed `localizationQuality` scan.
- The default check set is unchanged. Hosts choose checks with `checks` or `disabledChecks`, and a
  rule document's `disabledLocalizationChecks` disables more.

## Game Text: UE 4.27 object paths

- UE 4.27 usually saves `None` as a package's name, so its objects were named relative to the
  package (`DT_InventoryItems` rather than `/Game/Data/DT_InventoryItems.DT_InventoryItems`). Role
  matchers on `object_path` and same-package `class_path` values matched nothing on 4.27 projects,
  and String Table references and key changes could not find their entries.
- The corpus and the index now complete package-relative object paths, class paths and coverage gap
  paths from the package file under `Content/`, which Unreal mounts at `/Game`. Paths that are
  already complete are unchanged.
- The package text cache format is now `package-text-v3`, so existing caches read their packages
  again on the next refresh.

## Game Text: joined source cache

- Building a full join no longer fails with `Segment was not requested` when the join's source
  strings were already published in the shared index. The joined source cache loads the string
  segments it reads instead of relying on the caller to have loaded them.

## Upgrade notes

Use matching 0.15.0 packages and plugin artifacts, with Effect installed in the application as for
0.14.0.

Quality lists, exports and saved counts show fewer `missing_translator_notes` and
`duplicate_source` findings: one per line. Review-file acceptances of either check recorded under a
non-native culture no longer match a finding; presets that select either filter still load. Text
units without a localization key in UE 4.27 projects are identified by their completed object path,
so their IDs change.

Unreal plugins have no behavioral changes in this release; they advance for suite alignment.
Native plugin compatibility targets Unreal 5.7 and 5.8. Compiled variants require matching engine
version, BuildId, platform and architecture.

## Validation

Release preparation on 2026-10-15 uses Node 26 and pnpm 11.17.0.
