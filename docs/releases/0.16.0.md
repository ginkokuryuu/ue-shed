# UE Shed 0.16.0

UE Shed 0.16.0 tells player text from editor text in Game Text, folds compiled Blueprint copies into
the text a Blueprint authored, rates localization checks by severity and adds translation shape,
source and consistency checks, and evaluates source quality rules over the index. All 20 public npm
packages and eleven Unreal plugins advance to 0.16.0 together; packages without direct changes
advance for suite alignment and exact dependencies.

## Game Text: player and editor text

- Every occurrence records its `audience` (`player`, `editor` or `unknown`), the reason and the
  policy row that decided it. Unreal's own evidence comes first: uasset-io v1.11 adds
  `gather_editor_only` to package text record occurrences, from the package's gatherable text table.
  Otherwise the reviewed `TEXT_AUDIENCE_POLICY` table decides.
- Units, search results and localization lines roll their occurrences up: player if any is, else
  unknown if any is, else editor.
- Search and query take an `audience` filter, `facets.audiences` and `group: "audience"`. CSV
  exports add an Audience column.
- With a target that does not gather editor-only data, editor text that would read "Not gathered
  yet" is outside the target (`outOfScope: "editor_only_data_not_gathered"`), and localization
  checks skip it.

## Game Text: compiled Blueprint copies

- uasset-io v1.12 adds `blueprintClasses` to package text records: each Blueprint, its saved
  `GeneratedClass`, that class's default object, and a saved skeleton class.
- Game Text folds the generated class, instance, class default and skeleton copies of a widget or
  Blueprint text into the authored place. Nothing is folded from names alone.
- Each place keeps its copies in `copies`. A copy with other text no longer makes its key
  conflicting. When a copy the game runs holds other text, the line gets the `compiled_copy_differs`
  signal ("Blueprint not compiled since edit").
- A place's audience rolls up over the place and its copies, each classified from its own evidence.

## Game Text: check severity and new checks

- Every localization finding has a `severity` (`blocking`, `normal` or `low`). Workspace pages list
  blocking findings first and count findings by severity.
- New translation checks:
    - `format_argument_renamed`
    - `rich_text_tags`, `rich_text_tags_added` and `rich_text_tag_case`
    - `line_breaks` and `segment_separator`
    - `length_outlier` and `placeholder_translation`
    - `outdated_translation` and `source_line_endings_changed`
    - `inconsistent_translation`

    Shape checks skip empty translations, which `empty_translation` reports.

- New source checks that need no rule file: `culture_invariant_text`, `placeholder_text`,
  `source_whitespace`, `source_markup`, `number_only_text` and `string_table_key_collision`.
- Rule files take optional `segmentSeparator`, `optionalTags` and `optionalArguments`.
- Findings for keys with conflicting saved texts list them in `sourceVariants` instead of a joined
  string.
- Measured on a shipped UE 4.27 project with 237,931 lines and 10 cultures, with
  `missing_translator_notes` and `duplicate_source` disabled:
    - blocking findings went from 44,647 to 13, and all findings from 146,491 to 76,233;
    - the worst scan stall fell from about 4 s to under 1 s.

## Game Text: source quality over the index

- An opened index model's `sourceQuality(ruleDocument, { onProgress })` evaluates roles, character
  budgets and terminology page by page from index columns. It returns the same `TextQualityQuery` as
  `textQualityQuery(evaluateGameTextSourceQuality(corpus, ruleDocument))`.
- On a generated 583,507-line project the rules report took 29 s instead of 75 s. Peak heap fell
  from 1.7 GiB to 102 MiB, and the longest stall from 74 s to 0.27 s.

## Smaller changes

- The indexed localization quality scan reports progress through `onProgress`
  (`{ checkedLines, totalLines, findings }`).
- `@ue-shed/unreal-assets` turns a protocol worker closing its input early into a typed process
  failure instead of crashing Node. It rejects requests over the native reader's 4 MiB limit before
  starting the worker.

## Upgrade notes

- Use matching 0.16.0 packages and plugin artifacts, with Effect installed in the application as for
  0.14.0.
- Package text index formats move to `package-text-v5` and joins to `joined-v14`, so existing caches
  read their packages once more.
- Quality lists change:
    - new checks report;
    - `format_arguments` no longer reports renames;
    - `whitespace` compares edges only;
    - `duplicate_source` reports once per shared text;
    - findings carry `severity`.
- Hosts that switch the rules report to `sourceQuality` should evaluate before taking any
  publication lock and re-check ownership afterwards, as Workbench does.
- Unreal plugins have no behavioral changes in this release; they advance for suite alignment.

## Validation
